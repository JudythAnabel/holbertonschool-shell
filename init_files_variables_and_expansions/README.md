# Shell, Init Files, Variables and Expansions
- `0-alias`: creates an alias named ls with the value rm -f * (must be sourced to take effect).
- `1-hello_you`: prints hello followed by the current Linux user.
- `2-path`: adds /action to the end of PATH, so it is the last directory searched for programs.
- `3-paths`: counts the number of directories in PATH, ignoring empty entries.
- `4-global_variables`: lists all environment (global) variables.
- `5-local_variables`: lists all local variables, environment variables and functions.
- `6-create_local_variable`: creates a local variable named BEST with the value School.
- `7-create_global_variable`: creates a global (exported) variable named BEST with the value School.
- `8-true_knowledge`: prints the result of 128 plus the value of the environment variable TRUEKNOWLEDGE.
- `9-divide_and_rule`: prints the result of the environment variable POWER divided by DIVIDE.
- `10-love_exponent_breath`: displays the result of BREATH to the power LOVE.
- `11-binary_to_decimal`: converts the number stored in BINARY from base 2 to base 10.
- `12-combinations`: prints all combinations of two lowercase letters from aa to zz, one per line, except oo.
- `13-print_float`: prints the number stored in NUM with two decimal places.
